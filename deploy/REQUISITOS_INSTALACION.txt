SISGES — Requisitos e instalación en el cliente
Carpeta: C:\Silos\deploy
Fecha del paquete: 2026-08-26

1) QUÉ DESCARGAR / INSTALAR EN EL PC DEL CLIENTE
--------------------------------------------------------------------------------
A. Sistema operativo
   - Windows 10 / 11 (64 bits) recomendado

B. PostgreSQL (OBLIGATORIO)
   - Versión: 14, 15, 16, 17 o 18 (en desarrollo se usó 18)
   - Descarga oficial: https://www.enterprisedb.com/downloads/postgres-postgresql-downloads
   - Durante la instalación anote:
       * Puerto: 5432 (por defecto)
       * Contraseña del usuario postgres
   - Instale las herramientas de línea de comandos (bin: psql, pg_restore, pg_dump)
   - Deje el servicio "postgresql-x64-XX" en Automatic / iniciado

C. .NET Framework 4.8 (OBLIGATORIO para Sisges Pro)
   - Suele venir en Windows 10/11 actualizado
   - Si falta: https://dotnet.microsoft.com/download/dotnet-framework/net48

D. Visual C++ Redistributable (recomendado)
   - x64: https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

E. (Opcional) pgAdmin 4
   - Facilita ver la base y restaurar con interfaz
   - Viene con el instalador de PostgreSQL (EDB) si lo marca

F. Sisges (archivos a copiar)
   - Carpeta de la aplicación (Release o instalador):
       Sisges Pro.exe
       Sisges Pro.exe.config
       Sisges Configuracion.exe   ← configurar conexión sin login
       DLLs / ReportViewer / logo, etc.
   - Esta carpeta deploy\backup\ con los .backup


2) ARCHIVOS DE BACKUP INCLUIDOS (deploy\backup)
--------------------------------------------------------------------------------
  sisges_cliente_base_YYYYMMDD.backup
      → RECOMENDADO para instalar en cliente nuevo.
      → Incluye: estructura, procedimientos, usuarios, perfiles, productos,
        cooperativas (asociaciones), transportes, silos, conductores,
        productores, clientes (destinos), estatus, ítems de análisis, etc.
      → NO incluye movimientos de recepción/despacho ni tasas diarias
        (la romana arranca limpia).

  sisges_completo_YYYYMMDD.backup
      → Copia total de la BD de desarrollo (incluye recepciones/despachos de prueba).

  sisges_datos_maestros_YYYYMMDD.sql
      → Solo datos maestros en SQL (referencia / reparación parcial).


3) DATOS MAESTROS QUE LLEVAN EN LA BASE CLIENTE (estado al generar el backup)
--------------------------------------------------------------------------------
  Usuarios:
    - ADMIN  (perfil administrador)
    - ROMANA (perfil romana)
    * Las claves son las que ya tenía su sistema (encriptadas en BD).

  Productos: Maiz Blanco, Maiz Amarillo
  Cooperativas (asociaciones): Unica
  Transportes: Unica
  (+ silos, conductores, productores/clientes de catálogo, estatus, análisis)


4) PASOS RÁPIDOS EN EL CLIENTE
--------------------------------------------------------------------------------
  1. Instalar PostgreSQL y .NET 4.8
  2. Copiar carpeta Sisges + carpeta deploy
  3. Ejecutar como Administrador:
       deploy\restaurar_base_cliente.bat
     (crea la BD produccion_cliente_ y restaura sisges_cliente_base_*.backup)
  4. Ejecutar "Sisges Configuracion.exe"
       Servidor: localhost (o IP del servidor)
       Puerto: 5432
       Base: produccion_cliente_
       Usuario / clave de PostgreSQL
       Probar → Guardar cifrado
  5. Abrir Sisges Pro e iniciar sesión (ADMIN / ROMANA)
  6. Configurar tasa del día (admin) antes de recepciones
  7. Ajustar puerto de romana en AppSettings si aplica (COM1, etc.)


5) SI LA BASE YA EXISTE
--------------------------------------------------------------------------------
  - Restaurar SOBREESCRIBE objetos. Haga backup previo.
  - O cree otra BD (ej. produccion_cliente_nueva) y apunte Sisges Configuracion.


6) RED / SERVIDOR
--------------------------------------------------------------------------------
  - Si PostgreSQL está en otro PC: abra el puerto 5432 en el firewall
    y configure pg_hba.conf para permitir la IP del cliente.
  - En cada PC de romana: Sisges Configuracion → IP del servidor.


7) CHECKLIST ANTES DE ENTREGAR
--------------------------------------------------------------------------------
  [ ] PostgreSQL instalado y servicio corriendo
  [ ] BD produccion_cliente_ restaurada
  [ ] Sisges Configuracion: prueba de conexión OK y cifrado
  [ ] Login ADMIN y ROMANA OK
  [ ] Productos / cooperativas / transportes visibles
  [ ] Config. Tasa del día creada
  [ ] (Si hay báscula) puerto COM configurado
